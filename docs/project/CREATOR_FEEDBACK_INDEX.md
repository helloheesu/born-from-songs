# 창작자 피드백 인덱스

이 문서는 공개 프로토타입을 확인한 뒤 받은 피드백을 게임별 문서로 연결한다.
대화 원문과 실제 파일 정보는 공개하지 않고, 공개 출처 레지스터의 `SRC-004`를
근거로 삼아 실행 가능한 요약만 기록한다.

## 현재 작업 구분

| 게임 | 현재 구분 | 다음 작업의 중심 |
|---|---|---|
| Man in Word | 장기 개발·이번 해커톤 제출 제외 | 급조하지 않고 사랑에 관한 관찰·추리 구조와 고유 콘텐츠를 다시 설계 |
| 시스터 깨우기 | 해커톤 개선 후보 | 한 화면 피드백, 난이도, 콘티의 시각적 개성 |
| Forever Young | 해커톤 개선 후보 | 투구 버그 수정과 수비·송구를 포함한 야구 루프 |
| 이별선고 | 해커톤 개선 후보 | 실제 사용 환경의 시작 실패 재현 후 기획 방향 재평가 |
| 야간비행 | 해커톤 개선 후보 | 궤도 공명·색·유한한 생애 중심의 코어 규칙 재설계 |

네 해커톤 후보 중 최종 제출작과 제출 개수는 아직 결정하지 않았다. 현재 범위
밖의 후보에는 새 작업을 만들지 않는다.

## 해석 규칙

- `직접 피드백`은 창작자가 현재 프로토타입을 확인하고 밝힌 반응이나 선호다.
- `사용자 결정`만 현재 작업 범위를 바꾼다.
- 피드백에서 나온 아이디어는 채택 전까지 `미채택 제안`으로 둔다.
- 자동화 검증 결과와 실제 사용자가 겪은 문제를 서로 대체하지 않는다.
- 비공개 대화의 정확한 문장, 사진, 개인적 일화와 제3자 창작물의 표현은 공개
  문서에 옮기지 않는다.
