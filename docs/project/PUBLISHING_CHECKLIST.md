# GitHub 공개 전 점검

이 저장소는 공개 가능한 코드·문서만 추적하도록 정리했지만, 원격 저장소를
만들거나 push하기 전에는 아래 확인이 필요하다.

## 이미 Git에서 제외한 것

- 녹음, 전사, 메시지 내보내기, 원안, AI 대화, 콘티와 참고 자료 원본
- 로컬 분석 원문과 작업 식별자
- 배포 프로젝트 설정, 환경 변수, 인증서와 키
- 의존성, 빌드 결과, 브라우저 자동화 로그와 로컬 출력
- 개인 식별 이름을 포함한 이전 문서 경로와 QA 캡처

## 확인된 공개 결정

- `sister-wakeup` 게임 화면과 기존 배포 주소에 포함된 `희수` 표기는 공개할 수 있다.
- 공개 표시명은 `노래에서 태어난 게임들`, GitHub 저장소명은 `born-from-songs`이다.
- 공개 크레딧에는 희진·희수의 승인된 역할과 OpenAI Codex의 구현 보조만 기록한다. 이메일·성·프로필 링크는 넣지 않는다.
- 원본 코드와 창작물에는 오픈 소스 라이선스를 부여하지 않으며 재사용을 허용하지 않는다. 제3자 자료에는 각 권리자의 라이선스를 적용한다.
- 현재 `main` 이력의 코드와 공개 문서를 `born-from-songs` GitHub 공개 저장소에 게시한다.
- 다섯 게임의 개별 사이트를 공개하고, 주소는 저장소가 아닌 전달 메시지에서 공유한다.

## GitHub 게시 뒤에도 남은 확인

- 다섯 개별 사이트를 한 주소로 묶는 통합 허브가 필요한지 결정한다.
- 해커톤 제출 규정이 공개 저장소나 특정 라이선스를 요구하는지 확인한다.
- `CREDITS.md`의 공개 이름과 역할을 최종 제출본에서도 그대로 사용할지 확인한다.
- 게임·기여물별 저작권 귀속은 역할 크레딧과 별도로 다룬다.

공개 승인된 `희수` 표기 때문에 Git 이력을 다시 만들 필요는 없다. 공개 이름이나
크레딧 결정을 바꾸면 첫 push 전에 현재 이력 전체에서 해당 표기를 다시 검사한다.

## push 직전 검사

```bash
git status --short
git diff --cached --check
git ls-files
git grep -n 'Users/' -- .
git log --oneline --decorate --all
```

첫 공개 push 전에 검사 결과와 사용자 판단을 확인하고, 이후 공개 변경에서도
같은 검사를 반복한다.
