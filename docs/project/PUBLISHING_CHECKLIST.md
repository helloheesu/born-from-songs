# GitHub 공개 전 점검

이 저장소는 공개 가능한 코드·문서만 추적하도록 정리했지만, 원격 저장소를
만들거나 push하기 전에는 아래 사용자 판단이 필요하다.

## 이미 Git에서 제외한 것

- 녹음, 전사, 메시지 내보내기, 원안, AI 대화, 콘티와 참고 자료 원본
- 로컬 분석 원문과 작업 식별자
- 배포 프로젝트 설정, 환경 변수, 인증서와 키
- 의존성, 빌드 결과, 브라우저 자동화 로그와 로컬 출력
- 개인 식별 이름을 포함한 이전 문서 경로와 QA 캡처

## 공개 여부를 확인할 것

- `sister-wakeup` 게임 화면의 현재 제목과 문장에는 개인 이름이 포함되어 있다.
- 해당 사이트 래퍼에는 기존 공개 배포 주소가 메타데이터로 들어 있다.
- 게임 코드·문서·이미지에 적용할 라이선스와 공동 제작 크레딧이 미결정이다.

위 이름이나 주소를 비공개로 바꾸기로 하면 나중 커밋에서만 지워서는 안 된다.
공개 안전 기준선 커밋에도 현재 게임 UI가 있으므로, 첫 push 전에 로컬 Git
이력을 다시 만들어야 한다.

## push 직전 검사

```bash
git status --short
git diff --cached --check
git ls-files
git grep -n 'Users/' -- .
git log --oneline --decorate --all
```

검사 결과와 사용자 판단을 확인하기 전에는 공개 원격 저장소 생성이나 push를
진행하지 않는다.
