# 공개용 출처 레지스터

이 레지스터는 공개 문서가 로컬 전용 원본을 실제 파일명이나 경로 없이 가리키기 위한 식별자 목록이다. 식별자는 출처의 존재와 유형만 나타내며, 그 내용이 사용자 결정으로 채택되었다는 뜻은 아니다.

| ID | 공개 가능한 유형 설명 | 공개 상태 | 해석할 때의 주의점 |
|---|---|---|---|
| `SRC-001` | 기획 대화 기록과 텍스트 전사 | 로컬 전용 | 전사는 원기록의 편집 가능한 초안일 수 있다. |
| `SRC-002` | 스토리보드·콘티 자료 | 로컬 전용 | 시각 자료의 아이디어가 최종 구현 결정과 같지는 않다. |
| `SRC-003` | 초기 아이디어 메모 | 로컬 전용 | 초기안과 현재 범위를 구분한다. |
| `SRC-004` | 협업 대화 내보내기 | 로컬 전용 | 대화 속 제안과 합의된 결정을 분리한다. |
| `SRC-005` | AI 탐색 대화 기록 | 로컬 전용 | AI의 판단은 사용자 요구나 결정으로 간주하지 않는다. |
| `SRC-006` | 참고 게임 목록 | 로컬 전용 | 참고 대상과 구현 요구를 동일시하지 않는다. |
| `SRC-007` | 아이디어 정리·분석본 | 로컬 전용 | 파생 분석이며 직접 원기록이 아니다. |
| `SRC-008` | 실행 결정 정리의 원본 초안 | 로컬 전용 | 공개 결정 기록과 대조해 실제 채택 여부를 확인한다. |

## 인용 규칙

- 공개 문서에는 `SRC-003에 기록된 초기 아이디어`처럼 ID와 필요한 수준의 유형 설명만 쓴다.
- 원본 파일명, 실제 로컬 경로, 비공개 원본을 식별할 수 있는 이름, 연락처, 작업 식별자, 비공개 문장을 쓰지 않는다.
- 직접 요구, 구현 사실, 해석, 제안, 사용자 결정을 각각 표시한다.
- 정확한 인용이 꼭 필요하면 공개 가능 여부와 문구를 사용자에게 먼저 확인한다.

## 식별자 추가 절차

1. 로컬 대응표에 실제 원본과 다음 `SRC-*` ID를 연결한다.
2. 이 공개 레지스터에는 유형과 해석 주의점만 추가한다.
3. 관련 게임 문서에서는 ID만 참조한다.
4. `git diff --cached`에서 원본 이름이나 경로가 섞이지 않았는지 확인한다.
