# 결정 기록

이 문서는 채택된 사용자 결정과 아직 열린 선택을 구분한다. 구현에서 발견한 사실이나 에이전트 제안은 결정으로 기록하지 않는다.

## 채택된 사용자 결정

| ID | 날짜 | 결정 | 결과 |
|---|---|---|---|
| D-001 | 2026-08-24 | 하나의 프로젝트 폴더와 하나의 Git 저장소를 사용한다. | 게임별 하위 폴더를 둔 모노레포로 관리한다. |
| D-002 | 2026-08-24 | 공유 문서와 실행 코드를 함께 관리한다. | 각 게임 아래에 코드와 문서 경계를 둔다. |
| D-003 | 2026-08-24 | 공개하면 안 되는 원본도 같은 프로젝트 폴더에 둔다. | 로컬 전용 영역 전체를 Git 추적에서 제외한다. |
| D-004 | 2026-08-24 | 원본을 숨기면서 문서 근거는 유지한다. | 공개 문서는 `SRC-*`만 인용하고 실제 대응표는 로컬에만 둔다. |
| D-005 | 2026-08-24 | 이전 링크의 사용성을 가능한 한 보존한다. | 공개 경로 변환표와 로컬 전용 이전 경로 별칭을 사용한다. |
| D-006 | 2026-08-24 | 구조 변경 전후를 Git 이력에서 구분한다. | 공개 안전 기준선 커밋 뒤 구조 이동 커밋을 남긴다. |
| D-007 | 2026-08-24 | 활성 다섯 게임에만 작업을 집중한다. | 현재 범위 밖의 후보는 폴더·문서·작업 업데이트 대상에서 제외한다. |

## 미결정

| ID | 항목 | 결정 전 확인할 내용 |
|---|---|---|
| O-001 | 공개 GitHub 저장소 이름 | 프로젝트 대표 이름과 향후 범위 |
| O-002 | 라이선스 | 코드, 문서, 게임 자산 각각의 공개 허용 범위 |
| O-003 | 공개 크레딧 | 제작자·자료·도구별 표기 동의와 필요한 문구 |
| O-004 | 배포 | 게임별 공개 대상, 계정, 도메인, 갱신 절차 |

미결정 항목은 README나 설정에 임시값을 넣어 사실상 확정하지 않는다.
