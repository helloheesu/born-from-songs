# 원안 검토 안내

이 문서는 다섯 브라우저 게임의 원안과 현재 프로토타입 사이의 차이를 확인하고,
다음 제작 결정을 받기 위한 검토본입니다. 구현 방법이나 개발 기록보다 **게임의
중심 감정과 플레이 방식이 원안에 맞는지**를 먼저 봐 주세요.

## 먼저 확인할 것

1. 플레이 가능한 게임은 링크에서 직접 해 봅니다.
2. 각 게임의 `원안에서 확인된 중심`이 맞는지 확인합니다.
3. `현재 구현`에서 의도와 다른 부분을 표시합니다.
4. 각 질문 앞의 범주에 맞는 선택과 짧은 의견을 남깁니다.

이 문서의 원안 요약은 로컬 전용 기획 자료를 공개 가능한 범위에서 정리한
것입니다. 정확한 문장, 설정, 이미지와 비공개 대화 원문은 포함하지 않습니다.

전달 메시지에 넣을 다섯 공개 링크는 공개 배포 상태와 게임 실행 경로의 응답을
확인했습니다.

## 답변 방법

질문 앞의 범주에 따라 아래처럼 답하면 됩니다.

- **원안 확인:** `맞음 / 수정 필요`
- **현재 플레이:** `유지 / 변경`
- **미채택 제안:** `채택 / 일부 채택 / 보류`
- **미결정:** 제시된 선택지 또는 짧은 자유 답변

이 문서를 직접 편집하거나 GitHub 계정을 만들 필요는 없습니다. 아래 형식을
복사해 메신저로 답해도 충분합니다.

```text
게임:
- 원안 중심: 맞음 / 수정 필요
- 현재 플레이: 유지 / 변경
- 꼭 남길 것:
- 바꿀 것:
- 자유 의견:
```

## 1. Man in Word — 말보다 먼저

플레이: **전달 메시지의 링크 사용**

### 원안에서 확인된 중심

근거: 공개 출처 레지스터의 `SRC-001`, `SRC-002`, `SRC-003`

- 몇 개의 표현만 남은 편지를 받고 과거의 행동을 되돌아보며 맥락을 얻습니다.
- 처음에는 부정적으로 읽힌 표현이 행동을 관찰한 뒤 호감이나 배려로 다시
  해석됩니다.
- 정제된 말보다 행동이 마음에 가까울 수 있다는 주제를 다룹니다.

### 현재 구현

- 기억 장면의 두 곳을 조사해 표현 카드를 얻습니다.
- 얻은 카드를 편지의 빈칸에 배치하면 같은 문장의 의미가 달라지고 결말로
  이어집니다.
- 현재 경험은 본격 추리보다 `숨은 지점 찾기 + 카드 대응`에 가깝습니다.

### 원안에서 미결정

- 정확한 편지 문장, 행동 장면, 단서 획득 규칙과 오답·힌트 구조

### 미채택 제안

- 경쟁하는 두 해석을 세우고, 행동 관찰로 한 해석의 모순을 찾아 기각하는
  후속 추리 규칙

### 확인 질문

1. **[원안 확인]** 위의 `원안에서 확인된 중심`이 이 게임에서 꼭 지켜야 할
   내용이 맞나요?
2. **[현재 플레이]** 현재 플레이가 의도한 **재해석**을 전달하나요, 아니면 카드 맞추기로 더
   느껴지나요?
3. **[미결정]** 첫 편지의 문장, 처음 가능한 두 해석, 해석을 뒤집는 결정적 행동은 무엇이어야
   하나요?
4. **[미채택 제안]** 관찰과 추리를 강화하는 위 제안을 `채택 / 일부 채택 / 보류`
   중 어떻게 볼까요?

상세 참고: [현재 구현과 미채택 설계 제안](../../games/man-in-word/docs/DESIGN_PROPOSALS.md)

## 2. 시스터 깨우기 — 희수 깨우기

플레이: **전달 메시지의 링크 사용**

### 원안에서 확인된 중심

근거: 공개 출처 레지스터의 `SRC-001`, `SRC-002`, `SRC-003`

- 소리·조명·온도를 조절해 제한시간 안에 잠든 인물을 깨웁니다.
- 잠이 얕아지면서 사용할 수 있는 환경 요소가 늘어납니다.
- 너무 거슬리게 하면 화가 쌓이고, 적정 환경을 찾으면 깨우기에 성공합니다.

### 현재 구현

- `Deep Sleep → REM → Almost Awake → Awake` 순서로 진행됩니다.
- 소리부터 시작해 빛과 온도가 차례로 열리고, `Wake`와 `Angry`를 함께
  관리합니다.
- 마이크를 허용하지 않아도 슬라이더만으로 끝까지 플레이할 수 있습니다.

### 아직 임시인 것

- 90초 제한, 환경별 적정 범위, 분노 기준, A+/F 점수와 최고점 기록
- 마이크를 선택 기능으로 두고 실제 조도·온도 센서는 연결하지 않은 범위 결정

### 확인 질문

1. **[원안 확인]** 속도와 화를 내지 않는 조절 중 어느 쪽을 더 중요하게 느끼게
   해야 하나요? 둘의 균형이라면 어느 쪽에 더 무게를 둘까요?
2. **[현재 플레이]** 소리·빛·온도가 차례로 열리는 현재 플레이가 의도한 전략을
   보여 주나요?
3. **[현재 플레이]** 마이크 없이도 완주 가능한 현재 방식을 유지할까요?
4. **[미결정]** 주변 소리나 기기 움직임을 실제로 사용하는 체험이 핵심인가요,
   화면 조작만으로도 충분한가요?
5. **[미결정]** 제한시간과 점수에서 꼭 남기거나 먼저 바꿀 것은 무엇인가요?

상세 참고: [현재 구현 보고서](../../games/sister-wakeup/docs/IMPLEMENTATION_REPORT.md)

## 3. Forever Young — GO AHEAD

플레이: **전달 메시지의 링크 사용**

### 원안에서 확인된 중심

근거: 공개 출처 레지스터의 `SRC-001`, `SRC-002`, `SRC-003`, `SRC-004`

- 야구 선수의 성장과 노화를 타격 판정 범위의 변화로 느끼게 합니다.
- 은퇴 뒤 반복되는 일상을 지나 다시 훈련하고 복귀합니다.
- 복귀 뒤 홈런과 환호로 생애 서사를 마칩니다.

### 현재 구현

- 스윙 하나만을 반복 조작하는 방식으로 시즌 진행부터 복귀 홈런까지 완주할 수
  있습니다.
- 성장기에 판정 범위가 넓어지고, 노화 구간에서 다시 좁아집니다.
- 주루·수비·송구는 구현하지 않고 타격과 생애 서사에 집중했습니다.

### 아직 임시인 것

- 10개 시즌, 시즌당 공의 수, 판정 범위와 속도, 은퇴·훈련 횟수
- 성적과 관계없이 은퇴하고 복귀전 홈런으로 반드시 끝나는 규칙

### 확인 질문

1. **[원안 확인]** 가장 중요한 것은 성장·노화·은퇴·복귀의 생애 서사인가요, 야구 플레이의
   폭인가요?
2. **[미결정]** 다음 제작 단계는 타격에 집중하고 주루·수비·송구를 뒤로 미뤄도
   될까요?
3. **[현재 플레이]** 성적과 무관한 은퇴, 훈련 뒤 복귀, 홈런으로 끝나는 결말을
   유지할까요?
4. **[미결정]** 공개 제목과 가상 구단·선수 설정에서 바꿔야 할 것이 있나요?

상세 참고: [현재 구현 보고서](../../games/forever-young/docs/IMPLEMENTATION_REPORT.md)

## 4. 이별선고 — 마지막 문장

플레이: **전달 메시지의 링크 사용**

### 원안에서 확인된 중심

근거: 공개 출처 레지스터의 `SRC-001`, `SRC-006`

- 자동으로 달리며 이별의 말을 사랑 공격으로 지우는 아케이드 러너와, 기억을
  모아 이별 편지를 완성하는 두 후보가 있습니다.
- 어느 쪽이든 성적과 무관하게 결국 이별에 도달하는 감정선을 공유합니다.

### 현재 구현

- 러너 후보를 택해 짧게 누르면 점프하고 길게 누르면 사랑 공격을 보냅니다.
- 사랑 공격을 해도 앞선 상대와의 거리는 줄지 않고, 게이지의 의미는 관계에서
  혼자 설 힘으로 바뀝니다.
- 마지막 문장은 기존 행동으로 피할 수 없으며, 직접 받아들여야 결말로 갑니다.

### 아직 임시인 것

- 러너 후보를 택한 것 자체, 총 4층과 135초 진행, 기억 조각과 문구
- 충돌 뒤 바로 실패하지 않는 규칙과 마지막 문장을 받아들이는 종료 방식

### 확인 질문

1. **[원안 확인]** 중심 원안은 `아케이드 러너 / 편지 재구성 / 아직 결정하지
   않음` 중 어느 쪽인가요?
2. **[현재 플레이]** 결국 이별에 도달하고 직접 받아들이는 현재 결말이 의도한
   감정을 전달하나요?
3. **[미결정]** 사랑 공격, 기억 조각, 게이지의 의미 변화 중 꼭 남길 것은
   무엇인가요?
4. **[미결정]** 마지막에 플레이어에게 어떤 감정을 남기고 싶나요?

상세 참고: [현재 구현 보고서](../../games/breakup-notice/docs/IMPLEMENTATION_REPORT.md)

## 5. 야간비행

플레이: **전달 메시지의 링크 사용**

### 원안에서 확인된 중심

근거: 공개 출처 레지스터의 `SRC-001`, `SRC-003`, `SRC-007`

- 출발할 때 되고 싶은 모습을 고르고, 우주에서 직접 유영하며 별과 행성을
  방문합니다.
- 여행에서 기억과 글자 조각을 모아 마지막에 자신의 답을 만듭니다.
- 처음의 바람과 다른 답에 도달해도 여행에서 쌓은 삶의 가치를 인정합니다.

### 현재 구현

- 여섯 곳을 자유롭게 방문해 기억과 글자 조각을 모읍니다.
- 두 조각을 합쳐 세 개의 고정 정체성 단어 중 하나를 완성합니다.
- 점수·죽음·실패 없이 유영하고, 처음과 같은 답인지에 따라 결말 도입만
  달라집니다.

### 아직 임시인 것

- 여섯 기억의 내용, 세 정체성과 고정 조합, 시간대와 나이 표현
- 처음의 선택이 여행 중 사건은 바꾸지 않고 결말 문장에만 반영되는 구조

### 확인 질문

1. **[원안 확인]** 위의 삶의 가치와 자기 인정이 이 게임의 핵심 메시지가 맞나요?
2. **[현재 플레이]** 현재처럼 점수와 실패 없이 차분하게 유영하고 방문하는
   방식이 원안에 맞나요?
3. **[미채택 제안]** 마지막 답은 `준비된 세 단어로 충분 / 더 자유롭게 조합해야
   함 / 보류` 중 어느 쪽인가요?
4. **[미결정]** 처음 고른 바람이 결말 문장만 바꿀까요, 여행 중 사건에도 영향을
   줄까요?
5. **[미결정]** 여섯 기억 중 반드시 들어가야 할 장면이나 이미지가 있나요?

구체적인 원문이나 비공개 이미지를 답변에 붙일 때에는 공개 문서가 아니라 별도
비공개 채널로 전달해 주세요.

상세 참고: [현재 구현 보고서](../../games/night-flight/docs/IMPLEMENTATION_REPORT.md)
