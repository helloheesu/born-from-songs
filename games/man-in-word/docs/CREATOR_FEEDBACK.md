# Man in Word — 창작자 피드백

상태: **장기 개발·이번 해커톤 제출 제외**

이 문서는 `SRC-004`의 2026-08-24 프로토타입 검토 대화를 공개 가능한 수준으로
요약한다. 대화 원문과 개인적 표현은 포함하지 않는다.

## 직접 피드백

- 현재 프로토타입은 처음 구상과 차이가 있지만 짧은 구현 범위 안에서는 방향을
  일부 보여 준다. 다만 지금 상태는 게임보다 짧은 이야기 시연에 더 가깝다.
- 이 아이디어는 며칠 안에 제출용으로 급조하기보다 시간을 들여 제대로 발전시켜
  다른 기회에 활용하고 싶다는 의사가 확인됐다.
- 중심 의도는 상대의 말보다 행동을 관찰해 사랑의 의미를 추론하는 게임이다.
  처음에는 부정적으로 보이는 단서가 쌓이고, 관계를 다시 해석하는 순간이
  플레이어의 추리로 일어나야 한다.
- 편지를 처음 주는 대신 행동과 표현 조각을 먼저 모으고 마지막에 편지를 받는
  흐름도 후보로 제시됐다. 편지 자체가 너무 이른 호감 단서가 되는 문제를 피하기
  위한 안이지만 아직 채택되지는 않았다.
- 현재 공개 제목 `말보다 먼저`는 원하는 인상과 맞지 않는다. 새 제목은 아직
  정하지 않았다.

## 사용자 결정

- 이번 해커톤의 빠른 제출 후보에서 제외한다.
- 프로젝트와 원안은 보존하고 장기 개발 대상으로 관리한다.
- 기존 공개 프로토타입을 유지할지 내릴지는 별도로 결정하지 않았다.

## 현재 구현 사실

- 현재 프로토타입은 한 기억 장면에서 두 조사 지점을 찾고 표현 카드를 빈칸에
  배치하는 한 사이클을 제공한다.
- 경쟁 가설, 반증, 상태 변화와 재방문은 아직 구현되지 않았다.
- 현재 공개본은 장기 설계의 기준 사양이 아니라 비교 가능한 초기 탐색물이다.

## 미채택 제안

- 편지 작성자와 수신자의 관계, 후보 표현과 기억·감각의 대응은 잠정안이다.
- [게임성 설계 제안](./DESIGN_PROPOSALS.md)의 가설 보드, 인과 배열, 재방문과
  힌트 구조는 아직 채택되지 않았다.
- 특정 기존 작품을 연상시키는 결말 대신 고유한 마지막 이미지를 만들 필요가
  있지만, 그 이미지 자체는 미결정이다.

## 다시 시작하기 전에 정할 것

2. 편지를 받는 시점과 전체 사건 순서
3. 최종 문장과 대응하는 행동·기억·감각
4. 플레이어가 직접 수행할 추리의 핵심 규칙
5. 고유한 마지막 이미지와 제3자 작품 참고의 경계
