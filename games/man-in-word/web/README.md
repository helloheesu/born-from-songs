# Man in Word 웹 프로토타입

편지 읽기부터 행동 단서 수집, 빈칸 배치, 의미 반전, 엔딩까지 한 번 플레이할 수 있는 Vite 프로젝트입니다.

```bash
npm install
npm run dev
```

`npm run build`는 상대 경로 기반 정적 결과물을 `dist/`에 만들고, 번들에 포함된 제3자 소프트웨어 고지를 `dist/THIRD_PARTY_LICENSES.md`에 생성합니다. 현재 장면·문구·단서 조합은 한 사이클 검증을 위한 창작 초안입니다. 기획 상태와 후속 제안은 [게임 루트 문서](../README.md)에서 확인합니다.
