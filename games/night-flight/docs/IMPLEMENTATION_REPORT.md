# 야간비행 — 구현 보고서

상태: 유영·방문·글자 조합을 중심으로 한 브라우저 코어 루프 구현.

## 기획 근거

공개 원본 등록부의 `SRC-001`, `SRC-003`, `SRC-007`에서 다음 방향을 확인했다.

- 출발할 때 되고 싶은 모습을 고른다.
- 넓은 우주에서 직접 움직여 별과 행성을 방문하고 경험을 얻는다.
- 시간이 흐르며 여행자의 모습과 배경이 변한다.
- 방문 흔적과 글자 조각이 남는다.
- 마지막에 조각으로 자신의 답을 만들고, 처음의 바람과 달라도 삶의 가치를 인정한다.

`SRC-007`은 직접 요구의 근거가 아니라 원본의 위치와 미정 항목을 찾는 색인으로만 사용했다.

## 현재 구현 사실

- 세 개의 출발 정체성 중 하나를 선택한다.
- 방향키·WASD·포인터·화면 방향키로 여행자를 유영시킨다.
- 별이나 행성에 가까이 간 뒤 방문 입력을 한 번 더 해야 기억과 글자 조각을 얻는다.
- 방문한 빛에는 표시가 남고, 방문 수가 늘면 배경과 여행자의 시간대 표현이 변한다.
- 여섯 곳을 방문한 뒤 두 조각을 조합해 세 개의 고정 정체성 단어 중 하나를 완성한다.
- 처음과 같은 답인지 다른 답인지에 따라 결말 도입 문장이 달라진다.
- 방문에는 사망·점수 차감이 없고 잘못된 방문이나 조합은 상태를 잃지 않는 안내로 처리한다.
- 화면 단계와 방문·조합 상태를 명시적인 게임 상태로 관리한다.

## 프로토타입용 임시 판단

- 목적지 여섯 개와 기억 카드 여섯 개
- 세 개의 정체성과 두 조각짜리 고정 조합 세트
- 방문 수에 따라 바뀌는 네 시간대와 나이 표현
- 자유 유영의 약한 관성과 감속 수치
- 근접 후 별도 방문 버튼을 누르는 상호작용
- 같은 답과 다른 답에 적용되는 결말 도입 문장

이 값들은 원안에 없는 공백을 채운 프로토타입 규칙이며 최종 콘텐츠가 아니다.

## 구현하지 않은 범위

- 주마등 영상과 컷신 애니메이션
- 자유 단어 입력과 임의 글자 조립
- 실제 음원과 기존 작품의 제목·가사·멜로디 차용
- 시간대마다 달라지는 사건·결과 분기
- 점수 경쟁, 전투, 실패 엔딩
- 저장·계정·백엔드·랭킹·공유 기능

## 검증 기록

2026-08-24 기준으로 다음을 확인했다.

- TypeScript 검사와 Vite 프로덕션 빌드 통과
- 바람 선택부터 여섯 목적지 방문, 기억 수집, 조합, 결말까지 데스크톱·모바일 브라우저 완주
- 처음과 다른 답, 처음과 같은 답의 두 결말 도입 확인
- 데스크톱과 모바일에서 가로 넘침 없음
- 외부 네트워크 에셋 참조 없음
- 최종 검사에서 콘솔 오류·경고 없음
- 이동 감소 설정과 조각 버튼의 접근 가능한 이름 확인
