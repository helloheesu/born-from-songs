# 야간비행 — 구현 보고서

상태: **중력·궤도 공명·색·유한한 생애 중심의 90초 웹 프로토타입 구현**

## 기획 근거

공개 원본 등록부의 `SRC-001`, `SRC-003`, `SRC-007`에서 다음 방향을 확인했다.

- 소속이 사라진 뒤 경험이나 사람을 만나려면 스스로 움직여야 한다.
- 넓은 우주에서 다른 존재와 만나기 위해 자신의 궤도를 맞춘다.
- 잠시 함께 가다가 멀어지는 인연과 오래 나란히 가는 인연이 있다.
- 시간이 흐르며 여행자는 나이 들고, 지나온 항로와 만남의 흔적이 남는다.
- 처음 바란 모습과 실제 삶의 결과가 달라도 그 삶의 가치를 부정하지 않는다.

`SRC-007`은 직접 요구의 근거가 아니라 원본의 위치와 미정 항목을 찾는 색인으로만
사용했다.

## 사용자 결정

- 목적지 클릭·전부 방문·고정 글자 조합보다 게임 규칙을 먼저 다시 설계한다.
- 궤도를 맞추는 이동과 만남, 유한한 생애, 노화와 소멸을 중심으로 삼는다.
- 고정 글자 순서 맞히기는 필수 코어에서 제외한다.
- 웹에서 원하는 표현이 어렵다면 Unity를 검토하되 먼저 현재 웹 앱으로 물리
  프로토타입을 구현한다.
- 검증한 이번 물리 버전을 기존 공개판과 비교할 수 있는 별도 주소에 공개하고,
  이후 버전도 의미 단위 커밋·GitHub 동기화·공개 게시까지 이어서 처리한다.

## 현재 구현 사실 — 2026-08-25

### 이동과 중력

- DOM 목적지 지도를 1200×720 논리 좌표의 2D Canvas 시뮬레이션으로 교체했다.
- 여행자와 여섯 행성은 위치와 속도를 가지며, 행성의 질량과 거리에 따라 제한된
  중력이 여행자의 항로를 휘게 한다.
- 여행자가 색을 얻을수록 작은 중력 질량이 늘고 행성의 경로에도 약한 역방향
  영향이 적용된다.
- 방향키·WASD·화면 방향키·Canvas 포인터 추진을 지원한다. Space와 화면 중앙
  버튼은 현재 속도를 감쇠한다.
- 현재 속도와 활성 행성의 중력을 반영한 짧은 예상 항로를 점선으로 표시하며
  설정에서 끌 수 있다.

### 궤도 공명과 색

- 단순 충돌이나 방문 버튼을 제거했다.
- 행성 주위의 공명 띠 안에서 상대속도를 기준 이하로 일정 시간 유지해야 공명이
  성립한다.
- 공명을 유지한 시간과 상대속도로 내부 공명값을 누적한다.
- 공명 중 행성의 색이 여행자의 외곽 고리, 이동 흔적과 교환 입자에 점차 더해진다.
- 숫자 총점을 전면에 표시하지 않고 현재 색, 만난 궤도 수와 가장 긴 공명 시간을
  피드백으로 보여준다.

### 생애와 소멸

- 한 회차는 90초이며 나이는 18에서 80까지 연속해서 증가한다.
- 여섯 행성은 정해진 시각에 한 번씩만 들어오고 각자의 종료 시각에 떠난다.
  무한 생성하지 않으며 65초 이후에는 새 행성이 나타나지 않는다.
- 생애를 네 단계로 나누고 후반으로 갈수록 추진력을 낮추며 별빛과 화면 가장자리를
  어둡게 한다.
- 시간이 끝나면 여행자는 현재까지 얻은 색 입자로 흩어지고 항로는 화면에 남는다.
- 결과에는 만난 궤도 수, 가장 긴 공명, 남은 색 수를 표시한다. 고정 글자 조합과
  정답 판정은 없다.

### 접근성과 설정

- 키보드와 포인터·터치 조작, 일시정지, 소리 토글, 예상 항로 토글을 제공한다.
- Canvas와 조작 버튼에 접근 가능한 이름을 두고 신호 등장, 공명, 생애 단계와
  결말을 라이브 영역으로 알린다.
- 시스템의 움직임 감소 설정을 읽고 장식 애니메이션과 입자 수를 줄인다.

## 이전 기준선

2026-08-24 기준선은 되고 싶은 말 선택, 고정된 여섯 목적지 전부 방문, 기억과
글자 조각 수집, 두 조각으로 세 정체성 중 하나를 맞히는 구조였다. 이 루프는
완주 가능했지만 선택·숙련·결과가 약하다는 직접 피드백에 따라 현재 웹 소스에서
교체했다. 이전 공개판은 비교 기준선으로 보존했다.

2026-08-25에는 기존 공개판을 그대로 보존하고 별도 비교 사이트를 공개로 전환해
현재 물리 프로토타입을 사이트 버전 2로 배포했다.

## 프로토타입용 임시 판단

- 90초 생애와 18~80세 표시
- 여섯 행성의 위치·속도·질량·등장·퇴장 시각
- 중력 상수, 힘 제한, 추진력과 나이별 감소 폭
- 공명 거리 띠, 상대속도 상한과 잠금 시간
- 색 혼합 속도, 내부 공명값과 입자 수
- 현재 제목 문장, 행성 이름과 결과 문구

이 값들은 조작 감각을 검증하기 위한 구현값이며 최종 창작 규칙으로 확정하지
않았다.

## 검증 기록

2026-08-25 기준으로 다음을 확인했다.

- TypeScript 검사와 Vite 프로덕션 빌드 통과
- 실제 데스크톱 브라우저에서 추진 후 공명 3회, 색 3개, 90초 소멸 결말까지 완주

- 390px급 모바일 화면에서 가로 넘침 없이 Canvas, 상태 패널과 화면 조작 표시

- 프로덕션 사이트 래퍼에서 게임 iframe 로드와 콘솔 오류·경고 0건

## 구현하지 않은 범위

- 행성마다 다른 인물·사건·기억 콘텐츠
- 여행자의 색이 행성 표면에 영구적으로 남는 시각 상태
- 행성 등장 순서와 초기 궤도 위상의 회차별 변형
- 수치 점수표, 저장·계정·랭킹·공유 기능
- 3D 공간, Unity 포트와 실제 천체 물리 시뮬레이션
- 실제 음원과 기존 작품의 제목·가사·멜로디 차용

## 남은 검증과 미결정

- 창작자가 중력·추진·공명 조작을 재미있고 의도한 고독으로 느끼는지
- 실제 휴대폰에서 포인터 추진과 화면 방향키를 오래 조작할 때의 감각
- 노화에 따른 추진력 감소가 불쾌한 방해보다 감정 변화로 읽히는지
- 행성이 모두 사람을 나타낼지, 경험을 나타내는 다른 천체도 둘지
- 숫자 점수를 결과에 추가할지와 최종 색 혼합·흔적 표현
- 90초 실험 뒤 전체 회차 길이를 늘릴지
- 웹 프로토타입을 유지할지 Unity 전환 조건이 실제로 발생하는지
