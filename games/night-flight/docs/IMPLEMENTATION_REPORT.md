# 야간비행 — 구현 보고서

상태: **우주비행사·공명층·충돌·익명 궤도 메시지를 포함한 90초 웹 프로토타입 구현**

## 기획 근거

공개 원본 등록부의 `SRC-001`, `SRC-003`, `SRC-007`에서 다음 방향을 확인했다.

- 소속이 사라진 뒤 경험이나 사람을 만나려면 스스로 움직여야 한다.
- 넓은 우주에서 다른 존재와 만나기 위해 자신의 궤도를 맞춘다.
- 잠시 함께 가다가 멀어지는 인연과 오래 나란히 가는 인연이 있다.
- 시간이 흐르며 여행자는 나이 들고, 지나온 항로와 만남의 흔적이 남는다.
- 처음 바란 모습과 실제 삶의 결과가 달라도 그 삶의 가치를 부정하지 않는다.

`SRC-007`은 직접 요구의 근거가 아니라 원본의 위치와 미정 항목을 찾는 색인으로만
사용했다.

## 사용자 결정

- 목적지 클릭·전부 방문·고정 글자 조합보다 게임 규칙을 먼저 다시 설계한다.
- 궤도를 맞추는 이동과 만남, 유한한 생애, 노화와 소멸을 중심으로 삼는다.
- 고정 글자 순서 맞히기는 필수 코어에서 제외한다.
- 웹에서 원하는 표현이 어렵다면 Unity를 검토하되 먼저 현재 웹 앱으로 물리
  프로토타입을 구현한다.
- 검증한 이번 물리 버전을 기존 공개판과 비교할 수 있는 별도 주소에 공개하고,
  이후 버전도 의미 단위 커밋·GitHub 동기화·공개 게시까지 이어서 처리한다.
- 여행자는 무채색 우주비행사로 시작하고, 만남의 팔레트가 외곽 띠가 아니라
  우주복 내부를 비율대로 채운다.
- 생애가 끝나면 선택적으로 익명 메시지와 최종 팔레트를 서버에 남기고 이후
  플레이의 행성으로 다시 등장시킨다. 공개 전 기본 유해 표현 필터를 적용한다.
- 오라 안쪽에서는 안쪽 방사 접근 속도만 점차 감쇠하고, 표면 접촉은 색을 잃는
  충돌로 처리한다.
- 관계의 의미를 제목·인트로·결말의 설명 문장으로 쓰지 않고 시각·물리·소리와
  플레이어가 남긴 흔적으로 전달한다.

## 현재 구현 사실 — 2026-08-25

### 이동과 중력

- DOM 목적지 지도를 1200×720 논리 좌표의 2D Canvas 시뮬레이션으로 교체했다.
- 여행자와 여섯 행성은 위치와 속도를 가지며, 행성의 질량과 거리에 따라 제한된
  중력이 여행자의 항로를 휘게 한다.
- 여행자가 색을 얻을수록 작은 중력 질량이 늘고 행성의 경로에도 약한 역방향
  영향이 적용된다.
- 방향키·WASD·화면 방향키·Canvas 포인터 추진을 지원한다. Space와 화면 중앙
  버튼은 현재 속도를 감쇠한다.
- 현재 속도, 활성 행성의 중력과 공명층의 안쪽 방사 감쇠를 반영한 짧은 예상
  항로를 점선으로 표시하며 설정에서 끌 수 있다.
- 거리와 실제 중력 세기에 연속 반응하는 오라, 행성으로 휘는 먼지와 밝아지는
  예상 항로로 가까워질수록 영향이 커지는 것을 보여준다.
- 공명층 안에서는 행성 쪽으로 들어가는 상대 방사 속도만 점차 감쇠한다. 접선
  속도와 바깥으로 분리되는 속도는 보존해 반발이나 재흡착처럼 보이지 않게 했다.

### 궤도 공명과 색

- 충돌만으로 만남이 성립하는 규칙과 방문 버튼을 제거했다.
- 행성 주위의 공명 띠 안에서 상대속도를 기준 이하로 일정 시간 유지해야 공명이
  성립한다.
- 공명을 유지한 시간과 상대속도로 내부 공명값을 누적한다.
- 원형 여행자를 은회색 우주비행사 실루엣으로 교체했다. 공명 중 행성의 전체
  팔레트가 우주복 내부 면적, 이동 흔적과 교환 입자에 점차 더해진다.
- 저장된 다색 팔레트는 행성 표면의 색 띠와 혼합 오라로 보이며, 각 색이 다음
  여행자의 우주복에 별도 기여도로 남는다.
- 숫자 총점을 전면에 표시하지 않고 현재 색, 만난 궤도 수와 가장 긴 공명 시간을
  피드백으로 보여준다.

### 공명층과 충돌

- 행성 오라에 들어오면 메시지의 일부만 보이고, 공명 판정이 성립하면 전체가
  드러난다. 공명하지 않고 멀어지면 부분 메시지도 다시 흐려진다.
- 표면에 접근 중 닿으면 위치 겹침을 해소하고 법선 반발을 5.5%만 남기는 거의
  비탄성 충돌을 적용한다. 이미 바깥으로 분리 중이면 속도를 다시 꺾지 않는다.
- 새 접촉은 충격 속도에 따라 보유한 각 색의 5~12%를 잃게 한다. 흩어진 색은
  입자로 퍼지고 행성 표면의 얼룩으로 남으며 1.15초 재충돌 쿨다운을 둔다.

### 익명 궤도 메시지

- 사이트의 `GET /api/messages?limit=6`은 D1에서 공개 상태 메시지를 최대 여섯 개
  읽는다. 데이터가 부족하거나 조회할 수 없으면 클라이언트의 seed 메시지로
  보완한다.
- 90초 생애가 끝나면 최대 60자 메시지를 선택적으로 남길 수 있다. `POST
  /api/messages`는 메시지, 최종 팔레트 1~4색과 로컬 익명 token을 검증해 저장한다.
- 서버는 NFKC 정규화 뒤 욕설·위협, 링크, 이메일, 휴대·유선전화, 긴 숫자열과
  주요 연락처 handle을 우선 차단한다. 원문 IP는 저장하지 않고 임의 client
  token의 SHA-256만 저장해 시간당 성공 4회로 제한한다.
- D1 schema와 index는 Drizzle migration에 기록했고 배포 archive의
  `.openai/drizzle/`에 포함된다.

### 생애와 소멸

- 한 회차는 90초이며 나이는 18에서 80까지 연속해서 증가한다.
- 여섯 행성은 정해진 시각에 한 번씩만 들어오고 각자의 종료 시각에 떠난다.
  무한 생성하지 않으며 65초 이후에는 새 행성이 나타나지 않는다.
- 생애를 네 단계로 나누고 후반으로 갈수록 추진력을 낮추며 별빛과 화면 가장자리를
  어둡게 한다.
- 시간이 끝나면 여행자는 현재까지 얻은 색 입자로 흩어지고 항로는 화면에 남는다.
- 결과에는 만난 궤도 수, 가장 긴 공명, 남은 색 수를 표시한다. 고정 글자 조합과
  정답 판정은 없다.

### 접근성과 설정

- 키보드와 포인터·터치 조작, 일시정지, 소리 토글, 예상 항로 토글을 제공한다.
- Canvas와 조작 버튼에 접근 가능한 이름을 두고 신호 등장, 공명, 생애 단계와
  결말을 라이브 영역으로 알린다.
- 시스템의 움직임 감소 설정을 읽고 장식 애니메이션과 입자 수를 줄인다.
- 첫 회차는 최대 11.5초의 플레이형 인트로로 시작한다. 이때 HUD와 생애 타이머를
  숨기고 방향·공명 조작만 단계적으로 보여주며, 재시작에서는 인트로를 생략한다.
- 결말 메시지 입력을 modal dialog로 표시하고 뒤쪽 게임 조작을 inert 처리한다.

## 이전 기준선

2026-08-24 기준선은 되고 싶은 말 선택, 고정된 여섯 목적지 전부 방문, 기억과
글자 조각 수집, 두 조각으로 세 정체성 중 하나를 맞히는 구조였다. 이 루프는
완주 가능했지만 선택·숙련·결과가 약하다는 직접 피드백에 따라 현재 웹 소스에서
교체했다. 이전 공개판은 비교 기준선으로 보존했다.

2026-08-25에는 기존 공개판을 그대로 보존하고 별도 비교 사이트를 공개로 전환해
현재 물리 프로토타입을 사이트 버전 2로 배포했다.

같은 날 우주비행사, 공명층, 충돌 색 손실과 D1 익명 메시지를 포함한 source
commit을 Sites에 동기화하고 사이트 버전 3으로 공개 배포했다. 기존 기준선 주소와
별도 비교 주소의 이전 버전 기록은 보존했다.

## 프로토타입용 임시 판단

- 90초 생애와 18~80세 표시
- 여섯 행성의 위치·속도·질량·등장·퇴장 시각
- 중력 상수, 힘 제한, 추진력과 나이별 감소 폭
- 공명 거리 띠, 상대속도 상한과 잠금 시간
- 색 혼합 속도, 내부 공명값과 입자 수
- 현재 제목·행성 이름과 결과 문구
- 익명 메시지 seed 문장과 1차 필터 패턴·시간당 제한

이 값들은 조작 감각을 검증하기 위한 구현값이며 최종 창작 규칙으로 확정하지
않았다.

## 검증 기록

2026-08-25 기준으로 다음을 확인했다.

- TypeScript 검사와 Vite 프로덕션 빌드 통과
- 실제 데스크톱 브라우저에서 HUD 없는 인트로, 공명, 우주복 다색 채움과 90초
  소멸 결말까지 완주
- 행성 표면에 직접 추진해 보유 색이 100%에서 95%로 줄고 충돌 안내와 색 입자가
  발생하는 것을 확인
- 공명 유지에 따라 가장 긴 공명 시간이 증가하고 결과에 반영되는 것 확인
- 일시정지 중 남은 시간이 줄지 않고 재개되는 것 확인
- 375px급 모바일 화면에서 가로 넘침 없이 Canvas, 상태 패널과 화면 조작 표시
- 시작·비행·결말 화면의 브라우저 콘솔 오류·경고 0건
- 게임 빌드를 사이트 래퍼에 동기화한 뒤 사이트 프로덕션 빌드와 린트 통과
- 사이트 프로덕션 의존성 감사 0건
- 전체 의존성 감사에는 `drizzle-kit`의 개발 전용 `esbuild@0.18` 경로에서 moderate
  4건이 남는다. 제안된 강제 수정은 Sites 기준 고정 버전을 깨뜨리므로 적용하지
  않았고, 이 경로는 공개 런타임 번들에는 포함되지 않는다.
- 로컬 D1에서 정상 POST와 GET 재조회, 욕설·링크·유선전화·잘못된 JSON의 HTTP
  400 거절을 확인
- 같은 익명 token의 네 번째 성공 저장 뒤 다섯 번째 요청이 `Retry-After`와 HTTP
  429를 반환하는 것을 확인
- 공개 버전 3의 `/`, `/api/messages?limit=6`, `/og.png`가 HTTP 200으로 응답하고,
  `/game/index.html`은 `/game/`으로 HTTP 307 정규화된 뒤 최종 HTTP 200으로 응답
- 프로덕션 사이트 래퍼에서 게임 iframe 로드와 콘솔 오류·경고 0건
- 별도 공개 비교 주소의 버전 3에서 시작 화면과 실제 공명층 플레이 로드,
  브라우저 오류·경고 0건
- 공개 Sites D1의 `DB` binding과 `orbit_messages` table 생성 확인. 공개 검증
  시점의 row는 0개이며 공개 환경에는 테스트 메시지를 작성하지 않음

## 구현하지 않은 범위

- 행성마다 다른 인물·사건·기억 콘텐츠
- 행성 등장 순서와 초기 궤도 위상의 회차별 변형
- 신고, 관리자 검수·숨김·삭제, 이의 제기와 운영 dashboard
- 수치 점수표, 계정·랭킹·소셜 공유 기능
- 3D 공간, Unity 포트와 실제 천체 물리 시뮬레이션
- 실제 음원과 기존 작품의 제목·가사·멜로디 차용

## 남은 검증과 미결정

- 창작자가 중력·추진·공명 조작을 재미있고 의도한 고독으로 느끼는지
- 실제 휴대폰에서 포인터 추진과 화면 방향키를 오래 조작할 때의 감각
- 노화에 따른 추진력 감소가 불쾌한 방해보다 감정 변화로 읽히는지
- 익명 메시지가 담긴 행성 외에 사건·경험을 나타내는 다른 천체도 둘지
- 1차 자동 필터 뒤의 신고·관리자 검수·삭제와 메시지 운영 정책
- 숫자 점수를 결과에 추가할지와 최종 색 혼합·흔적 표현
- 90초 실험 뒤 전체 회차 길이를 늘릴지
- 웹 프로토타입을 유지할지 Unity 전환 조건이 실제로 발생하는지
