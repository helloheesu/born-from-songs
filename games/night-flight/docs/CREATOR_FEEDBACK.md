# 야간비행 — 창작자 피드백

상태: **해커톤 개선 후보·최종 선정 미정**

이 문서는 `SRC-004`의 2026-08-24 프로토타입 검토 대화를 공개 가능한 수준으로
요약한다. 대화 원문과 개인적 경험의 구체 내용은 포함하지 않는다.

## 직접 피드백

- 이 게임은 넓은 우주에서 홀로 움직이는 진짜 고독한 감정이 나야 한다.
- 현재 공개본은 원하는 방향보다 지나치게 명랑하게 느껴진다.
- 다른 게임을 전반적으로 밝게 하자는 의견의 예외로 관리해야 한다.
- 구현 전에 원하는 느낌을 충분히 상세히 적지 않았으므로 현재 여섯 목적지와
  정체성 조합을 최종 콘텐츠로 간주하면 안 된다.

## 현재 구현 사실

- 여섯 목적지를 방문하고 기억과 글자 조각을 모아 답을 완성하는 루프는 끝까지
  동작한다.
- 현재의 색, 움직임, 효과음과 문장 톤은 고독보다 안전하고 명랑한 탐색에 가깝다는
  창작자 평가를 받았다.
- 목적지, 기억, 세 정체성과 조합 규칙은 프로토타입용 임시값이다.

## 미채택 제안

- 고독을 표현할 색, 공간 밀도, 이동 저항, 소리, 텍스트 양과 만남의 빈도는 아직
  정하지 않았다.
- 처음의 선택이 여행 중 사건을 바꿀지, 마지막 문장에만 반영될지도 미결정이다.
- 준비된 세 단어와 더 자유로운 글자 조합 중 어느 쪽을 사용할지 결정하지 않았다.

## 다음 작업 전에 정할 것

1. 고독함을 판단할 시각·소리·이동 기준
2. 목적지가 사람, 사건, 경험 중 무엇을 나타내는지
3. 여섯 기억에 들어갈 고유한 장면과 공개 가능한 범위
4. 처음 선택이 여행 과정에 미치는 영향
5. 마지막 답의 조합 자유도와 종료 연출
