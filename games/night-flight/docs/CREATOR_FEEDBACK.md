# 야간비행 — 창작자 피드백

상태: **해커톤 개선 후보·최종 선정 미정**

이 문서는 `SRC-004`의 2026-08-24 프로토타입 검토 대화를 공개 가능한 수준으로
요약한다. 대화 원문과 개인적 경험의 구체 내용은 포함하지 않는다.

## 직접 피드백

- 이 게임은 넓은 우주에서 홀로 움직이는 진짜 고독한 감정이 나야 한다.
- 현재 공개본은 원하는 방향보다 지나치게 명랑하게 느껴진다.
- 다른 게임을 전반적으로 밝게 하자는 의견의 예외로 관리해야 한다.
- 구현 전에 원하는 느낌을 충분히 상세히 적지 않았으므로 현재 여섯 목적지와
  정체성 조합을 최종 콘텐츠로 간주하면 안 된다.
- 원형 플레이어보다 처음의 우주비행사 형태가 메타포에 더 맞으며, 무채색으로
  출발해 만남의 색이 외곽 띠가 아니라 우주복 자체를 비율대로 채우면 좋다.
- 행성은 행성 형태를 유지하되 색 이름이 아니라 사람의 흔적처럼 느껴지는 짧은
  메시지를 품고, 플레이가 끝나면 완성한 색과 메시지를 다음 플레이에 남길 수
  있으면 좋다.
- 가까워질수록 중력이 강해지는 사실이 글을 읽지 않아도 오라와 끌려가는 효과로
  보여야 한다. 다만 오라 안쪽에서는 접근 속도가 조금씩 느려지고, 완전히 닿으면
  충돌로 색을 잃는 규칙을 원한다.
- 외로움과 색의 의미를 작가 문장으로 직접 설명하지 않고, 시각적 미장센과
  플레이 규칙으로 보여줘야 한다.

- 2026-08-25: 이전 플레이어가 마지막에 남긴 익명 메시지와 최종 팔레트를 서버에

## 현재 구현 사실

- 기존의 여섯 목적지 전부 방문·기억·고정 글자 조합 루프는 현재 웹 소스에서
  90초 궤도 공명 프로토타입으로 교체했다.
- 여섯 행성이 유한한 시각에 한 번씩 지나가며, 제한된 중력과 직접 추진으로
  공명 거리와 상대속도를 맞춘다.
- 공명 시간과 안정도는 내부 값으로 누적되고 우주비행사 내부의 다색 면적, 이동
  흔적, 만난 수와 가장 긴 공명으로 표현된다.
- 거리와 중력 세기에 연속 반응하는 오라, 휘어진 먼지와 예상 항로가 행성의
  영향을 보여준다. 오라에서는 안쪽 방사 속도만 감쇠하며 접선 이동은 유지된다.
- 오라 진입 시 행성 메시지의 일부가 보이고 공명하면 전체 메시지와 팔레트가
  드러난다. 서버 메시지가 없거나 조회에 실패하면 공개 가능한 seed 여섯 개를
  사용한다.
- 행성 표면에 접근 중 접촉하면 거의 비탄성으로 속도가 정리되고 충격에 따라
  보유 색의 5~12%가 입자로 흩어지며 행성 표면에 색 얼룩이 남는다.
- 나이는 18에서 80까지 흐르고 후반에 추진력과 별빛이 약해진다. 마지막에는 새
  행성이 오지 않으며 여행자는 색 입자로 소멸한다.
- 생애가 끝나면 최종 팔레트와 선택적 60자 메시지를 D1에 저장할 수 있다. 서버는
  욕설·위협·링크·연락처를 우선 차단하고 익명 token당 시간당 4회로 제한한다.
- 웹 Canvas 구현으로 데스크톱에서 공명, 충돌 색 손실, 90초 결말과 메시지 저장을
  확인했다.

  있다. Unity 채택은 결정하지 않았다.
