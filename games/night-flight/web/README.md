# 야간비행 웹 프로토타입

추진, 중력, 상대속도 기반 궤도 공명, 우주복 내부의 색 변화, 노화와 소멸을 90초
회차에 담은 2D Canvas 물리 프로토타입입니다. 행성의 오라에 진입하면 익명
메시지의 일부가 보이고, 공명하면 전체 메시지와 색이 우주복에 남습니다. 표면과
충돌하면 충격에 따라 보유한 색의 5~12%가 흩어집니다.

```bash
npm install
npm run dev
```

`npm run build`는 상대 경로 기반 정적 결과물을 `dist/`에 만들고, 번들에 포함된
제3자 소프트웨어 고지를 `dist/THIRD_PARTY_LICENSES.md`에 생성합니다. 방향키·WASD,
화면 방향키와 포인터 추진을 지원하며 Space 또는 중앙 버튼으로 감속합니다.
사이트 래퍼에서 실행할 때는 `/api/messages`를 사용하며, 독립 Vite 서버에서는
안전한 seed 메시지로 폴백합니다.
기획 경계는 [게임 루트 문서](../README.md)와
[규칙 재설계안](../docs/GAME_RULES_PROPOSAL.md)에서 확인합니다.
