# 야간비행

유한한 생애 동안 지나가는 행성의 중력을 읽고 궤도를 맞추며, 서로에게 남긴
색으로 자신의 항로를 만드는 짧은 물리 게임입니다.

## 현재 구현

- 90초 동안 여섯 행성이 한 번씩 지나가고 65초 이후에는 새 행성이 오지 않습니다.
- 추진·관성·제한된 상호 중력과 상대속도를 이용해 행성의 공명 띠에 머뭅니다.
- 공명 시간에 따라 여행자에게 색과 항로 흔적이 더해지고, 생애가 끝나면 색
  입자로 소멸합니다.
- 마우스·터치·키보드, 감속, 일시정지, 예상 항로와 소리 설정을 지원합니다.
- 외부 이미지·폰트·음원 없이 Vite 정적 게임으로 동작합니다.
- `web/`은 Vite 정적 게임이고, `site/`는 공개 배포용 전체 화면 래퍼입니다.

## 실행

```bash
cd games/night-flight/web
npm install
npm run dev
```

정적 빌드는 `npm run build`로 만듭니다. 사이트 래퍼는
`cd ../site && npm install && npm run sync-game && npm run build`로 별도
갱신·검증합니다.

## 현재 제한

- 현재 90초, 여섯 행성, 물리·공명·색 수치는 조작 검증용 임시값입니다.
- 행성마다 다른 인물·사건·기억 콘텐츠와 회차별 궤도 변화는 없습니다.
- 숫자 점수표, 저장·계정·랭킹·공유 기능은 없습니다.
- Unity 전환은 결정하지 않았으며 현재 구현은 2D Canvas입니다.
