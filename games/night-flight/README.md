# 야간비행

유한한 생애 동안 지나가는 행성의 중력을 읽고 궤도를 맞추며, 서로에게 남긴
색으로 자신의 항로를 만드는 짧은 물리 게임입니다.

## 현재 구현

- 90초 동안 여섯 행성이 한 번씩 지나가고 65초 이후에는 새 행성이 오지 않습니다.
- 무채색 우주비행사는 추진·관성·제한된 상호 중력과 상대속도를 이용해 행성의
  공명 띠에 머뭅니다.
- 행성의 중력은 거리와 힘에 따라 오라·휘어진 먼지·예상 항로로 드러납니다.
  오라 안에서는 안쪽으로 향하는 방사 속도만 점차 감쇠하고 접선 속도는
  보존됩니다.
- 공명하면 이전 플레이어가 남긴 메시지가 전부 보이고, 그 팔레트가 우주복
  내부와 항로 흔적을 비율대로 채웁니다. 표면 충돌은 충격에 따라 색의 5~12%를
  흩뜨리고 행성에 얼룩을 남깁니다.
- 생애가 끝나면 선택적으로 60자 익명 메시지와 최종 팔레트를 남길 수 있습니다.
  사이트의 D1 저장소에 남은 메시지는 이후 회차의 행성으로 다시 등장합니다.
- 마우스·터치·키보드, 감속, 일시정지, 예상 항로와 소리 설정을 지원합니다.
- 외부 이미지·폰트·음원 없이 Vite 정적 게임으로 동작합니다.
- `web/`은 Vite 정적 게임이고, `site/`는 공개 배포용 전체 화면 래퍼입니다.

## 실행

```bash
cd games/night-flight/web
npm install
npm run dev
```

정적 빌드는 `npm run build`로 만듭니다. 사이트 래퍼는
`cd ../site && npm install && npm run sync-game && npm run build`로 별도
갱신·검증합니다.

## 현재 제한

- 현재 90초, 여섯 행성, 물리·공명·색 수치는 조작 검증용 임시값입니다.
- 현재 메시지 필터와 익명 token 제한은 1차 안전장치입니다. 신고, 관리자 검수·
  삭제, 이의 제기와 운영 정책은 아직 없습니다.
- 행성마다 다른 인물·사건·기억 콘텐츠와 회차별 궤도 변화는 없습니다.
- 숫자 총점, 계정, 랭킹과 소셜 공유 기능은 없습니다.
- Unity 전환은 결정하지 않았으며 현재 구현은 2D Canvas입니다.
