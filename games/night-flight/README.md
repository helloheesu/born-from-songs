# 야간비행

별과 행성 사이를 직접 유영하며 기억과 글자 조각을 모으고, 마지막에 자신의 정체성 단어를 완성하는 짧은 탐색 게임입니다.

## 현재 구현

- 바람 선택, 유영, 여섯 곳 방문, 기억 수집, 글자 조합, 결말까지 완주할 수 있습니다.
- 마우스·터치·키보드를 지원하며 이동 감소와 소리 끄기 설정이 있습니다.
- 외부 이미지·폰트·음원 없이 Vite 정적 게임으로 동작합니다.
- `web/`은 Vite 정적 게임이고, `site/`는 공개 배포용 전체 화면 래퍼입니다.

## 실행

```bash
cd games/night-flight/web
npm install
npm run dev
```

정적 빌드는 `npm run build`로 만듭니다. 사이트 래퍼는
`cd ../site && npm install && npm run sync-game && npm run build`로 별도
갱신·검증합니다.

## 현재 제한

- 기억 카드와 세 개의 조합 답은 프로토타입용 고정 콘텐츠입니다.
- 자유 단어 조합, 영상, 저장·계정·랭킹 기능은 없습니다.
- 선택은 사건 순서를 바꾸지 않고 결말 도입 문장에만 반영됩니다.
