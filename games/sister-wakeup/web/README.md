# 시스터 깨우기 웹 프로토타입

소리·빛·온도를 조절해 제한시간 안에 잠든 인물을 깨우는 Vite 프로젝트입니다.

```bash
npm install
npm run dev
```

`npm run build`는 상대 경로 기반 정적 결과물을 `dist/`에 만들고, 번들에 포함된 제3자 소프트웨어 고지를 `dist/THIRD_PARTY_LICENSES.md`에 생성합니다. 마이크는 선택 입력이며 localhost 또는 HTTPS에서 권한이 필요합니다. 세부 구현 경계와 남은 실기기 검증은 [게임 루트 문서](../README.md)에서 확인합니다.
