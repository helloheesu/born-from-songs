# 시스터 깨우기 — 창작자 피드백

상태: **해커톤 개선 후보·최종 선정 미정**

이 문서는 `SRC-004`의 2026-08-24 프로토타입 검토 대화를 공개 가능한 수준으로
요약한다. 대화 원문, 사진과 개인적 외모 정보는 포함하지 않는다.

## 직접 피드백

- 콘티의 단순한 도형 결합과 장난스럽고 엉뚱한 캐릭터 인상을 살리고, 시각 요소를
  현재보다 복잡하게 만들지 않는 방향을 선호한다.
- 반응 영역과 조작 영역이 동시에 보이지 않아 값 변화의 결과를 바로 이해하기
  어렵다. 스크롤 없이 한 화면에서 조절과 반응을 함께 보는 구성이 필요하다.
- 현재 난이도는 예상보다 높고 잠에서 깨는 속도가 느리다. 중간 정도의 값을 찾으면
  진행이 더 빠르게 느껴지길 기대한다.
- 화면 입력만 반복하기보다 소리나 기기 움직임처럼 플레이어의 실제 행동이
  게임에 반영되는 상호작용을 원한다.
- 재촉하는 표현에 화를 내거나 입력 후보를 힌트로 보여 주는 방식도 제안됐다.

## 현재 구현 사실

- 현재는 소리·빛·온도를 슬라이더로 조절하며, 마이크만 선택 입력으로 사용할 수
  있다.
- 조작과 캐릭터 반응이 세로 화면의 서로 다른 영역에 있어 작은 화면에서는
  스크롤이 생길 수 있다.
- 제한시간, 적정 범위, Wake 증가 속도와 Angry 기준은 프로토타입용 임시값이다.

## 미채택 제안

- 마이크, 기기 움직임, 주변 밝기 또는 근접 행동 중 어떤 입력을 사용할지는 아직
  정하지 않았다.
- 특정 표현 입력에 따른 반응과 입력 힌트도 채택 전 제안이다.
- 센서를 쓰더라도 지원하지 않는 기기의 대체 조작은 별도 설계가 필요하다.

## 다음 작업 전에 정할 것

1. 모바일 한 화면에서 반드시 함께 보여 줄 정보와 조작
2. 목표 한 판 길이와 Wake 증가 속도
3. 콘티에서 공개 게임에 옮길 시각 요소
4. 실제 기기 입력의 우선순위와 권한 거절 시 대체 조작
5. 최종 제출 후보로 평가할 플레이테스트 기준
