# 시스터 깨우기 — 구현 보고서

상태: 브라우저 코어 루프 구현. 실제 마이크 장치 입력은 별도 실기기 확인 필요.

## 기획 근거

공개 원본 등록부의 `SRC-001`, `SRC-002`, `SRC-003`에서 다음 요구를 확인했다.

- 소리·조명·온도를 조절해 제한시간 안에 잠든 인물을 깨운다.
- 수면 단계가 `Deep Sleep → REM → Awake`로 변한다.
- 진행에 따라 사용할 수 있는 환경 요소가 늘어난다.
- 분노가 일정 횟수에 도달하거나 시간이 끝나면 실패하고, 조건을 지켜 깨우면 성공한다.
- 소리는 실제 마이크 입력 후보가 있으나 단어 인식은 요구되지 않았다.

## 현재 구현 사실

- 소리만 가능한 단계에서 시작해 빛과 온도가 차례로 열린다.
- 각 환경 값에 반응 없음, 반응 있음, 편안함 피드백이 있다.
- Wake 진행도와 Angry 누적을 함께 관리한다.
- 제한시간 안에 Wake가 완료되면 A+, Angry 한도 도달 또는 시간 만료 시 F 결과를 표시한다.
- 결과 화면에서 모든 상태를 초기화해 다시 시작할 수 있다.
- 마이크 권한이 없어도 소리 슬라이더로 완주할 수 있다.
- 키보드의 `Space` 입력은 소리를 켜고 끄는 토글로 작동한다.

## 프로토타입용 임시 판단

다음은 원안의 확정값이 아니라 한 판을 닫기 위한 구현값이다.

- 제한시간 90초
- 내부 Wake 범위 0–100과 단계 전환 기준
- 소리·빛·온도의 편안한 범위
- 점수 계산과 로컬 최고점 저장
- 실제 온도 센서 대신 슬라이더 사용
- 실제 마이크를 필수가 아닌 선택 입력으로 제공

## 구현하지 않은 범위

- 실제 조도·온도 센서
- 마이크 필수 모드와 단말별 음량 보정
- 카메라 가리기나 마이크에 바람 불기 같은 장치별 입력
- 여러 날에 걸친 수면 성향 변화
- 장편 서사와 최종 아트·음향

## 검증 기록

2026-08-24 기준으로 다음을 확인했다.

- TypeScript 검사와 Vite 정적 빌드 통과
- 시작부터 모든 수면 단계를 거쳐 A+ 결과까지 브라우저 완주
- 시간 만료 F와 Angry 한도 도달 F 재현
- 결과 화면 다시 시작과 로컬 최고점 동작
- 데스크톱과 모바일 뷰포트에서 주요 조작 확인
- 마이크 권한 없이 슬라이더로 완주
- 화면 부분 갱신 후 슬라이더 포커스와 드래그 유지
- 단계 전환 뒤 키보드 포커스 복구
- 지연된 마이크 권한 응답이 종료 뒤 남지 않도록 스트림 정리 경로 확인

기존 QA 캡처에는 공개 문서에서 사용하지 않는 개인 식별 이름이 게임 제목으로 포함되어 있어 로컬 검증 자료로만 보관한다.

## 남은 검증

- 실제 휴대폰·노트북 마이크의 상대 음량 입력
- 기기별 권한 거절·재요청 흐름
- 실제 스피커에서 효과음 음량 균형
- 최종 콘텐츠가 확정된 뒤 난이도와 제한시간 재조정
