# Forever Young 웹 프로토타입

성장·노화·은퇴·훈련·복귀를 한 번의 타격 입력으로 진행하는 Vite 프로젝트입니다.

```bash
npm install
npm run dev
```

정적 빌드는 `npm run build`, 빌드 미리보기는 `npm run preview`로 실행합니다. 빌드 결과에는 번들에 포함된 제3자 소프트웨어 고지인 `dist/THIRD_PARTY_LICENSES.md`가 생성됩니다. 이번 버전은 타격만 구현했으며 주루·수비·송구는 보류했습니다. 근거와 임시 구현 판단은 [게임 루트 문서](../README.md)에서 확인합니다.
