# Forever Young — 구현 보고서

상태: 타격 중심 브라우저 코어 루프 구현. 주루·수비·송구는 보류.

## 기획 근거

공개 원본 등록부의 `SRC-001`, `SRC-002`, `SRC-003`, `SRC-004`에서 다음 방향을 확인했다.

- 타격·주루·수비·송구를 포함하는 야구 게임을 구상했다.
- 시간이 흐르며 판정 범위가 넓어져 전성기를 맞고, 이후 다시 좁아져 노화를 규칙으로 느끼게 한다.
- 은퇴 뒤 반복되는 일상을 지나 공과 글러브를 계기로 훈련하고 복귀한다.
- 복귀 뒤 홈런과 환호로 끝나는 결말을 둔다.
- 최신 화면 구성에는 연도, 볼카운트, 타격 판정 범위, 수비와 송구 흐름이 포함되어 있다.

최신 화면 구성은 경기 안의 타격·수비·송구를 구체화하고, 초기 기록은 은퇴 뒤 일상과 복귀 결말을 담고 있다. 현재 구현은 두 자료에서 타격 화면 문법과 생애 결말을 결합한 프로토타입이다.

## 현재 구현 사실

- 마우스 클릭, 터치, `Space`를 하나의 스윙 입력으로 처리한다.
- 타이밍 위치에 따라 홈런, 안타, 스트라이크를 판정한다.
- 시즌 진행에 따라 판정창이 넓어졌다가 다시 좁아진다.
- 마지막 시즌 뒤 은퇴하고, 반복 일상과 타격 훈련을 거쳐 복귀한다.
- 복귀전은 홈런이 나올 때까지 파울 뒤 재시도할 수 있으며 홈런으로 종료된다.
- 외부 이미지·폰트·음원 없이 CSS 도형과 Web Audio를 사용한다.

## 프로토타입용 임시 판단

- 공개 제목과 가상 구단·상대 팀·등번호
- 10개 시즌과 시즌당 공 3개
- 판정 범위, 이동 속도, 나이와 점수 변화의 수치
- 성적과 무관하게 마지막 시즌 뒤 은퇴하는 규칙
- 반복 일상의 길이와 공·글러브 발견 장면
- 타격 훈련 8회와 복귀전 재시도 규칙

이 값들은 원안의 확정 설정이 아니며 기획 결정에 따라 교체할 수 있다.

## 구현하지 않은 범위

- 주루 중 방향 전환
- 외야 수비와 공 궤적 변화
- 방향·강도를 조절하는 송구
- 수비 결과에 따른 승리·역전패 분기
- 부상에 따른 은퇴
- 실제 선수·구단·방송 화면과 기존 음원 사용
