# 이별선고 — 창작자 피드백

상태: **해커톤 개선 후보·실사용 시작 문제 확인 필요**

이 문서는 `SRC-004`의 2026-08-24 프로토타입 검토 대화를 공개 가능한 수준으로
요약한다. 대화 원문과 제3자 게임의 구체 표현은 포함하지 않는다.

## 직접 피드백

- 이별을 피하려 애쓰면서도 결국 이별에 도달하는 고군분투의 감각이 중요한
  출발점이다.
- 공개본을 실제로 확인할 때 게임이 시작되지 않는다는 보고가 있었다. 당시에는
  정확한 기기·브라우저·입력 단계와 오류 화면을 기록하지 못했다.
- 현재 구현 전에 이 게임의 원하는 느낌을 충분히 상세하게 적지 않았다는 우려가
  있었으므로, 현재 러너 버전을 최종 원안으로 간주하면 안 된다.
- 야간비행을 제외한 다른 후보와 마찬가지로 현재보다 밝고 읽기 쉬운 화면을
  선호한다.

## 현재 구현 사실

- 자동화 검증에서는 시작부터 결말까지 상태 전환과 빌드가 통과했다.
- 창작자의 실제 사용 환경에서는 시작 단계가 막혔으므로 `실제 플레이 확인 완료`로
  볼 수 없다.
- 짧게 누르기와 길게 누르기, 사랑 공격, 기억 조각, 게이지 변화와 마지막 수용은
  현재 프로토타입의 구현 판단이다.

## 미채택 제안

- 아케이드 러너와 편지 재구성 중 최종 방향은 결정하지 않았다.
- 현재 공개 제목 `마지막 문장`도 최종 확정된 제목이 아니다.
- 밝은 화면을 적용할 때 이별의 정서를 어떤 색과 대비로 유지할지도 미결정이다.

## 다음 작업 순서

1. 실제 사용 환경과 같은 조건에서 시작 실패를 재현하고 원인을 기록
2. 시작 안내와 짧게·길게 누르기 입력이 즉시 이해되는지 확인
3. 문제 해결 뒤 현재 러너 루프를 창작자가 끝까지 플레이
4. 러너와 편지 재구성 중 중심 방향 결정
5. 마지막 감정, 제목과 화면 톤 결정
