# 이별선고 — 구현 보고서

상태: 아케이드 러너 버전의 브라우저 코어 루프 구현. 구현안 선택은 아직 최종 기획 결정이 아님.

## 기획 근거

공개 원본 등록부의 `SRC-001`, `SRC-006`에서 두 구현 후보를 확인했다.

1. 자동 전진하며 장애물을 넘고 코인을 모으고, 앞선 연인이 보내는 이별의 말을 사랑 공격으로 쳐내는 아케이드 러너
2. 과거를 회상해 단어를 얻고 마지막에 이별 편지를 완성하는 편지 재구성

두 후보 모두 성적과 무관하게 결국 이별에 도달한다는 감정선을 공유한다. 현재 프로젝트는 첫 번째 후보를 선택해 플레이 가능한 프로토타입으로 만든 것이며, 이 선택 자체를 확정 기획으로 기록하지 않는다.

## 현재 구현 사실

- 화면과 주인공이 자동으로 전진한다.
- 화면 버튼과 `Space`를 짧게 누르면 점프하고 길게 누르면 사랑 공격을 보낸다.
- 장애물을 피하고 공중의 기억 조각을 모으며, 이별의 말을 공격으로 지울 수 있다.
- 사랑 공격이 앞선 연인에게 닿아도 거리는 줄지 않는다.
- 진행 중 게이지의 의미가 관계 상태에서 혼자 설 힘으로 바뀐다.
- 마지막 문장은 기존의 점프와 공격으로 해결되지 않는다.
- 플레이어가 문장을 받아들이는 버튼을 눌러야 결말로 전환한다.
- 상태는 `title → running → final-line → ending`으로 관리한다.

## 프로토타입용 임시 판단

- 공개 제목, 총 4층, 전체 진행 시간 135초
- 짧게/길게 누르기의 경계값
- 연인과의 표시 거리와 기억 조각 명칭
- 장애물·이별 낌새·마지막 문장의 문구
- 게이지의 이름과 의미가 드러나는 시점
- 충돌 뒤 즉시 패배하지 않고 계속 달리는 규칙
- 마지막 문장을 명시적 버튼으로 받아들이는 종료 방식

## 구현하지 않은 범위

- 편지 재구성 버전
- 최종 층 수와 정식 난이도 곡선
- 참고한 옛 게임의 와이어 이동
- 층마다 달라지는 관계 장면이나 적
- 점수 경쟁, 로컬 최고 기록, 여러 결말
- 최종 아트·오리지널 음향·명칭 확정

참고작의 캐릭터·이미지·소리·UI는 차용하지 않았다. 화면은 HTML/CSS 도형으로 만들고 효과음은 Web Audio로 생성한다.

## 검증 기록

2026-08-24 기준으로 다음을 확인했다.

- TypeScript 검사와 Vite 빌드 통과
- 시작, 자동 질주, 마지막 문장, 수용, 결말 상태 전환 확인
- 실제 버튼 입력에서 짧게 누르기와 길게 누르기 판정 확인
- 일시정지 상태 전환 확인
- 모바일 뷰포트에서 가로 넘침 없이 원버튼 컨트롤 표시
- 이동 감소 환경의 대체 스타일 적용
- 브라우저 스모크 테스트 중 JavaScript 페이지 오류 없음
